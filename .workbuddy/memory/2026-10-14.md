## 排查 cc switch 误显示 Claude / Claude Desktop「已安装」
- 现象：cc switch 应用列表显示 Claude Code 2.1.195 与 Claude Desktop「已接入」，但用户认为早已卸载、找不到安装文件。
- 结论：
  1. Claude Code 其实**没卸载**，仍在 `C:\Users\kuma\.local\bin\claude.exe`（约 224MB，native 安装，`--version` 实测返回 2.1.195）。该目录**不在 PATH**，因此命令行敲 `claude` 无效，造成「已卸载」错觉。cc switch 直接扫描已知安装路径，不依赖 PATH，所以仍能识别。
  2. Claude Desktop 主程序**确实已卸载**（无 `%LOCALAPPDATA%\AnthropicClaude`、无注册表卸载项、无开始菜单快捷方式、无残留进程），但留下了配置残留目录：`AppData\Local\Claude`、`AppData\Local\Claude-3p`（configLibrary 内含 "CC Switch" 记录）、`AppData\Local\claude-cli-nodejs`。
  3. cc switch 的「官方 provider」记录（claude-official / claude-desktop-official）是**首次运行无条件播种**的（日志：Seeded official provider…，DB settings `official_providers_seeded=true`），与是否真装无关；加上配置目录存在 → 显示为已接入。
- 关键路径：`~/.cc-switch/{cc-switch.db, settings.json, live-state.json, logs/cc-switch.log, backups/}`；`~/.claude.json`（Claude Code 配置，installMethod=native，numStartups=80）。
